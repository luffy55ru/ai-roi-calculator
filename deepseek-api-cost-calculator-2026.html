DeepSeek R1, V3 & OpenAI 2026 Pricing FAQ

What is the DeepSeek V3 and DeepSeek R1 API pricing per 1M tokens in 2026? +

DeepSeek V3 (deepseek-chat) is priced at $0.27 per 1M input tokens (cache miss) and $1.10 per 1M output tokens. DeepSeek R1 (deepseek-reasoner) is priced at $0.55 per 1M input tokens (cache miss) and $2.19 per 1M output/reasoning tokens.

How does DeepSeek context cache hit pricing work? +

When requests share identical prompt prefixes (system prompts, tool schemas, or RAG context), DeepSeek automatically serves cached prefixes at ~75% off: $0.07/1M on DeepSeek V3 and $0.14/1M on DeepSeek R1. Raising cache hit rate from 0% to 70% can cut input spend dramatically on long-context workflows.

How does DeepSeek compare to OpenAI o3-mini, GPT-4o, and Claude 3.7 Sonnet? +

OpenAI o3-mini charges $1.10 / $4.40 ($0.55 cached input), GPT-4o charges $2.50 / $10.00 ($1.25 cached input), and Claude 3.7 Sonnet charges $3.00 / $15.00 ($0.30 cached input) per 1M tokens. DeepSeek R1 is typically ~50% cheaper than o3-mini and ~78%–85% cheaper than GPT-4o and Claude 3.7 Sonnet.
